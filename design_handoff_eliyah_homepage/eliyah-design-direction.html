Every system is designed, built, and tuned entirely in-house — a custom, hand-crafted piece brought into full harmony with the space it lives in. Set in Fraunces for display, Manrope for body and UI — both free, both licensable for commercial use without friction.
Fraunces · display, logotype-adjacent

Signature Move

Duotone photography. Every product and interior photo carries the same warm-brass-to-aubergine grade — never a flat, neutral shot. It's the visual version of what the brand already does to sound: shaping it around the space instead of leaving it raw. This is the one place color does heavy lifting; everywhere else, the interface stays quiet.
